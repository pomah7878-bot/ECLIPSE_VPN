# Утилиты для админа

Все утилиты **только читают**: ничего не меняют на сервере и в панелях, не печатают ключи, пароли и токены.
Запускаются из папки бота (например, `/root/EclipseVPN`).

## Проверка безопасности сервера — `sec_check.py`

Запускать на сервере бота. Что проверяет:
- какие порты открыты наружу;
- включён ли файрвол (ufw);
- настройки SSH и fail2ban;
- права на `config.py`, `secrets.env` и базу;
- ожидающие обновления безопасности ОС;
- заголовки сайта (HSTS, nosniff, CSP);
- что `config.py`, база и `.git` недоступны через сайт.

```
python3 scripts/sec_check.py https://example.com
```

Адрес сайта можно не вспоминать, бот подставит его сам:

```
python3 scripts/sec_check.py "$(venv/bin/python -c 'from database.requests import get_effective_webapp_url as g; print(g() or "")')"
```

Значки: 🟢 хорошо, 🟡 стоит поправить, 🔴 исправить сразу.

## Нагрузка на бота — `perf_report.py`

Отчёт о нагрузке, при каждом запуске пересобирается заново:
- система и процесс бота (процессор, память, потоки);
- размер базы и самые большие таблицы;
- зависания цикла событий;
- самые частые сообщения журнала.

```
python3 scripts/perf_report.py --hours 6
```

## Проверка IP на блокировку в России — `ip_pick.py`

Проверяет адреса через cheburcheck.ru, как это делает кнопка «🛰 Проверить на блокировку». Пригодится, когда хостер предлагает выбрать новый IP: сначала проверьте варианты, потом меняйте.

```
venv/bin/python scripts/ip_pick.py 203.0.113.10 203.0.113.20
```

Значки: 🟢 без блокировок, 🟡 единичные, 🔴 заблокирован (30% сканеров и больше).

## Подбор цели REALITY — `reality_scan.py`

Запускать **на том сервере**, для которого выбирается цель (`dest`), потому что задержка меряется с него.

Требования к цели:
- TLS 1.3 и HTTP/2;
- валидный сертификат;
- поддержка X25519.

Скрипт сортирует подходящие цели по задержке и печатает готовые `dest` и `serverNames`.

```
python3 reality_scan.py                        # встроенный список российских сайтов
python3 reality_scan.py --file domains.txt     # свой список
python3 reality_scan.py --neighbors 203.0.113.0/24   # сайты по соседству в сети хостера
```

Нужен только Python 3.8+, бот на этом сервере не требуется.

## Аудит панели 3x-ui — `panel_audit.py`

Запускать на сервере панели. Показывает настройки Xray:
- inbound'ы и outbound'ы;
- маршрутизацию;
- уровень логов;
- цели REALITY.

IP-адреса заменяются метками `IP#1`, `IP#2`, …

```
python3 panel_audit.py
```

## Ноды мастер-панели — `node_probe.py`

Показывает, какие ноды есть на мастер-панелях 3x-ui и к каким нодам привязаны inbound'ы. Помогает разобраться перед кнопкой «🧩 Ноды мастер-панели».

```
venv/bin/python scripts/node_probe.py
```

## Остальное

- `check_release.sh` — проверка перед релизом, что в коммит не попало личное.
- `migrate_export.sh` / `migrate_import.sh` — перенос бота на другой сервер.
