# Как помочь проекту

Спасибо, что хотите улучшить ECLIPSE Unlimited VPN.

- **Нашли ошибку** — создайте issue по шаблону «Сообщить об ошибке» и приложите версию бота (тег релиза) и фрагмент лога без токенов и ключей.
- **Есть идея** — issue «Предложить функцию»: опишите задачу, а не только решение.
- **Хотите прислать код** — откройте issue и обсудите изменение до pull request. Небольшие pull request с понятным описанием проверяются быстрее.
- **Уязвимости** — не в публичные issue, см. [SECURITY.md](SECURITY.md).

Платные функции и лицензия описаны в [LICENSING.md](LICENSING.md). Изменения, обходящие лицензию, не принимаются.
