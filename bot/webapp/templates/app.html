Почему система предупреждает? Это не вирус

Android предупреждает о любом приложении, которое устанавливается не из Google Play. Для ECLIPSE это ожидаемое и безопасное поведение.

  • APK подписан ключом ECLIPSE. Android при обновлении сверяет подпись с установленной — подменить файл чужой сборкой нельзя.
  • Приложение распространяется с официального сайта, а не из Google Play. Поэтому система и называет его «неизвестным» — это не признак заражения.
  • Файл можно проверить. SHA-256 скачанного APK и отпечаток подписи опубликованы ниже — сверьте их самостоятельно.
  • Никаких лишних доступов. Приложение не запрашивает контакты, SMS, геолокацию, микрофон и доступ ко всем файлам.

Обновления приходят из официального канала ECLIPSE и проверяются по SHA-256 перед установкой.

Проверьте файл самостоятельно

Версия и SHA-256 подтягиваются с сервера. Если значения совпадают — скачан ровно тот файл, который мы собрали.

Play Protect заблокировал установку — что нажать
  1. На экране предупреждения нажмите «Подробнее» (или «Дополнительные сведения»).
  2. Выберите «Установить всё равно» / «Всё равно установить» и подтвердите.
  3. Если кнопки нет: откройте Google Play Маркет → профиль → Play Защита → ⚙ → на время выключите «Сканировать приложения с помощью Play Protect» (или «Улучшенную защиту»).
  4. Установите APK и включите проверку обратно — так безопаснее для вас.
Huawei / HONOR — «Выявлена угроза»

AppGallery может показать экран «Выявлена угроза» / «Приложение не прошло проверку».

  1. Кнопка «УСТАНОВИТЬ» находится внизу экрана — иногда её нужно прокрутить или подождать несколько секунд.
  2. Если кнопки нет: Настройки → Безопасность → Дополнительные настройки → Установка приложений из внешних источников → разрешите для браузера/файлового менеджера.
  3. На HONOR (MagicOS): Настройки → Безопасность → Проверка приложений — временно отключите для внешних источников.
  4. В «Режиме Pure» установка извне запрещена — отключите Pure Mode на время установки.
Xiaomi / Redmi / POCO — проверка приложения
  1. При открытии APK приложение «Безопасность» может показать «Проверка приложений»/«Анализ угроз».
  2. Нажмите «Установить без проверки» / «Продолжить установку» / «Всё равно установить» (на MIUI кнопку иногда нужно удерживать ~10 секунд).
  3. Если блокирует наглухо: Настройки → Пароли и безопасность → Конфиденциальность → Особые разрешения → Установка неизвестных приложений — разрешите браузеру. Либо в приложении «Безопасность» → Настройки → Проверка приложений — выключите на время.
  4. HyperOS: Настройки → Безопасность → Проверка приложений.
Samsung — Автоблокировщик
  1. Обычно достаточно разрешить «Установку неизвестных приложений» для браузера.
  2. Если включён Автоблокировщик (Auto Blocker): Настройки → Безопасность и конфиденциальность → Автоблокировщик — выключите на время установки (или нажмите «Установить всё равно», если предлагает).
  3. После установки верните Автоблокировщик в прежнее состояние.
