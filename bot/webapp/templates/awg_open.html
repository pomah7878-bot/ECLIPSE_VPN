Конфигурация AmneziaWG

Скачайте файл и откройте его в приложении AmneziaVPN или AmneziaWG.

⬇️ Скачать конфигурацию
Как подключиться:
iPhone: после загрузки откройте файл → «Поделиться» → AmneziaVPN (или AmneziaWG).
Android: откройте файл → «Открыть с помощью» → AmneziaVPN, либо в приложении «+» → «Файл».
Компьютер: в приложении «+» → «Файл» → выберите скачанный .conf.

⚠️ Файл личный — никому его не отправляйте. Один файл — одно устройство.
