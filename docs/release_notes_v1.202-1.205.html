v1.202 — открыть в AmneziaVPN

  • Кнопка «📲 Открыть в AmneziaVPN» у каждого подключения AmneziaWG: импорт одним касанием.
  • Ключ не попадает в адрес страницы: используется короткоживущий токен на 15 минут.
  • Страница не кэшируется и не индексируется. Работает только с лицензией.
  • Для отдельного приложения AmneziaWG остаются файл .conf и QR.
